Jellyfin integration

        
Disk access is all it needs

        
No plugins, no server changes. Point JellySqueeze at your library folders and it works.

        

          

            
Basic mode — no key needed

            
Read/write access to the media folders is enough. Scan any library on demand, with per-library bitrate, encoder, and language settings.

          

          

            
Smart mode — add your API key

            
Paste a Jellyfin API key and unlock Recently Added: a daily schedule that checks what's new in your libraries and converts only those arrivals. Your library stays squeezed on its own.

          

        

      


      
      

        
Features

        
Everything a big library needs

        
GPU speed when you have it, safe CPU fallback when you don't.

        
    
          
  • GPU accelerationNVIDIA NVENC, Intel QSV, AMD VA-API, or plain CPU.
    • 
          
  • H.264 / H.265 outputPick the codec per library, with matching hardware encoders.
    • 
          
  • Target bitrate engineOnly oversized files are re-encoded; the rest skip in milliseconds.
    • 
          
  • Language cleanupKeep just the audio & subtitle languages you actually speak.
    • 
          
  • Resume-safeEvery finished file is logged — stop anytime, pick up where you left off.
    • 
          
  • Live progressPer-file bars, logs, and run history over WebSocket.
    • 
          
  • Recently AddedAdd your Jellyfin API key and nightly scans convert only new arrivals.
    • 
          
  • SchedulerDaily schedules run while you sleep — full library or new items only.
    • 
          
  • Atomic replacementOriginals are swapped only after validation passes.
    •
